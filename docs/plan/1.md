## 1.1 Config System

### Goal
Sistem konfigurasi yang fleksibel, mendukung file config, environment variable, dan default values.

### Struktur

```
internal/config/
├── config.go          # Config struct + loader
├── config_test.go     # Unit tests
└── defaults.go        # Default values
```

### Config File Location
```
%APPDATA%/AnagataSentinel/config.yaml    # Windows
~/.config/anagatasentinel/config.yaml    # Linux/macOS
```

### Sample Config (`config.yaml`)

```yaml
app:
  name: "AnagataSentinel"
  version: "1.0.0"
  debug: false

window:
  width: 1280
  height: 800
  min_width: 1024
  min_height: 640

database:
  path: "data/sentinel.db"
  password: ""  # Override via env: ANAGATA_DB_PASSWORD

logging:
  level: "info"        # debug, info, warn, error
  file: "logs/app.log"
  max_size_mb: 50
  max_backups: 3
  compress: true

splash:
  enabled: true
  duration_ms: 10000
```

### Environment Variable Override

| Config Path | Env Variable | Default |
|---|---|---|
| `database.password` | `ANAGATA_DB_PASSWORD` | `0123456789` |
| `logging.level` | `ANAGATA_LOG_LEVEL` | `info` |
| `app.debug` | `ANAGATA_DEBUG` | `false` |

### Implementation

```go
package config

import (
    "os"
    "path/filepath"

    "gopkg.in/yaml.v3"
)

type Config struct {
    App      AppConfig      `yaml:"app"`
    Window   WindowConfig   `yaml:"window"`
    Database DatabaseConfig `yaml:"database"`
    Logging  LoggingConfig  `yaml:"logging"`
    Splash   SplashConfig   `yaml:"splash"`
}

type AppConfig struct {
    Name    string `yaml:"name"`
    Version string `yaml:"version"`
    Debug   bool   `yaml:"debug"`
}

type WindowConfig struct {
    Width     int `yaml:"width"`
    Height    int `yaml:"height"`
    MinWidth  int `yaml:"min_width"`
    MinHeight int `yaml:"min_height"`
}

type DatabaseConfig struct {
    Path     string `yaml:"path"`
    Password string `yaml:"password"`
}

type LoggingConfig struct {
    Level       string `yaml:"level"`
    File        string `yaml:"file"`
    MaxSizeMB   int    `yaml:"max_size_mb"`
    MaxBackups  int    `yaml:"max_backups"`
    Compress    bool   `yaml:"compress"`
}

type SplashConfig struct {
    Enabled  bool `yaml:"enabled"`
    Duration int  `yaml:"duration_ms"`
}

func Load() (*Config, error) {
    cfg := defaultConfig()

    path, err := configPath()
    if err != nil {
        return cfg, nil
    }

    if _, err := os.Stat(path); err == nil {
        data, err := os.ReadFile(path)
        if err != nil {
            return nil, err
        }
        if err := yaml.Unmarshal(data, cfg); err != nil {
            return nil, err
        }
    }

    applyEnvOverrides(cfg)

    return cfg, nil
}

func configPath() (string, error) {
    appData := os.Getenv("APPDATA")
    if appData == "" {
        home, err := os.UserHomeDir()
        if err != nil {
            return "", err
        }
        appData = filepath.Join(home, ".config")
    }
    return filepath.Join(appData, "AnagataSentinel", "config.yaml"), nil
}

func applyEnvOverrides(cfg *Config) {
    if v := os.Getenv("ANAGATA_DB_PASSWORD"); v != "" {
        cfg.Database.Password = v
    }
    if v := os.Getenv("ANAGATA_LOG_LEVEL"); v != "" {
        cfg.Logging.Level = v
    }
    if v := os.Getenv("ANAGATA_DEBUG"); v != "" {
        cfg.App.Debug = v == "true"
    }
}
```

## 1.2 Structured Logging

### Goal
Logging terstruktur dengan output ke console dan file, mendukung log rotation.

### Struktur

```
internal/logger/
├── logger.go          # Logger setup
├── logger_test.go     # Unit tests
└── rotate.go          # Log rotation
```

### Log Output Format

**Console (development):**
```
15:04:05 INF [BOOT] Application startup
15:04:05 INF [BOOT] Stage 'Initializing database' complete
15:04:07 ERR [BOOT] Stage 'Initializing security' failed error="connection timeout"
```

**File (production):**
```json
{"time":"2026-09-10T15:04:05Z","level":"INFO","msg":"[BOOT] Application startup"}
{"time":"2026-09-10T15:04:07Z","level":"ERROR","msg":"[BOOT] Stage failed","error":"connection timeout","stage":"security"}
```

### Log Levels

| Level | Use Case |
|---|---|
| `debug` | Detailed diagnostic info |
| `info` | General operational messages |
| `warn` | Unexpected but non-fatal |
| `error` | Failures that need attention |

### Implementation

```go
package logger

import (
    "io"
    "log/slog"
    "os"
    "path/filepath"
)

func Setup(cfg *config.LoggingConfig) *slog.Logger {
    var level slog.Level
    switch cfg.Level {
    case "debug":
        level = slog.LevelDebug
    case "warn":
        level = slog.LevelWarn
    case "error":
        level = slog.LevelError
    default:
        level = slog.LevelInfo
    }

    opts := &slog.HandlerOptions{
        Level: level,
    }

    var writers []io.Writer
    writers = append(writers, os.Stdout)

    if cfg.File != "" {
        if err := os.MkdirAll(filepath.Dir(cfg.File), 0755); err == nil {
            f, err := os.OpenFile(cfg.File,
                os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0644)
            if err == nil {
                writers = append(writers, f)
            }
        }
    }

    writer := io.MultiWriter(writers...)

    var handler slog.Handler
    if cfg.Level == "debug" {
        handler = slog.NewTextHandler(writer, opts)
    } else {
        handler = slog.NewJSONHandler(writer, opts)
    }

    return slog.New(handler)
}
```

## 1.3 Error Handling UI

### Goal
Tampilkan error ke user dengan cara yang user-friendly, bukan cuma log.

### Struktur

```
internal/errors/
├── errors.go          # Error types
└── dialog.go          # Error dialog (Walk)
```

### Error Types

```go
package errors

type ErrorLevel int

const (
    LevelInfo ErrorLevel = iota
    LevelWarning
    LevelError
    LevelFatal
)

type AppError struct {
    Level   ErrorLevel
    Stage   string
    Message string
    Err     error
    Retriable bool
}

func (e *AppError) Error() string {
    if e.Err != nil {
        return fmt.Sprintf("%s: %v", e.Message, e.Err)
    }
    return e.Message
}

func (e *AppError) Unwrap() error {
    return e.Err
}
```

### Error Dialog (Windows)

```
┌──────────────────────────────────────────┐
│  ⚠ AnagataSentinel                       │
│                                          │
│  Failed to initialize database.          │
│                                          │
│  Error: connection refused               │
│  Stage: Initializing database            │
│                                          │
│  [Retry]  [Close Application]            │
└──────────────────────────────────────────┘
```

### Error Flow

```
Boot Stage Failed
       │
       ▼
  Log Error ──► Store in App.startupError
       │
       ▼
  Backend Ready ──► Check startupError
       │
       ├── nil ──► showMainApp()
       │
       └── error ──► showErrorDialog(error)
                          │
                          ├── Retry ──► Re-run failed stage
                          └── Close ──► Shutdown app
```

### Implementation

```go
package errors

import (
    "github.com/lxn/walk"
    . "github.com/lxn/walk/declarative"
)

func ShowErrorDialog(err *AppError) {
    var dlg *walk.Dialog

    buttons := []Widget{
        PushButton{
            Text: "Close",
            OnClicked: func() {
                dlg.Close()
            },
        },
    }

    if err.Retriable {
        buttons = append([]Widget{
            PushButton{
                Text: "Retry",
                OnClicked: func() {
                    dlg.Close()
                },
            },
        }, buttons...)
    }

    Dialog{
        AssignTo: &dlg,
        Title:    "AnagataSentinel",
        MinSize:  Size{Width: 400, Height: 200},
        Layout:   VBox{},
        Children: []Widget{
            Label{
                Text: err.Error(),
                Font: Font{PointSize: 10},
            },
            Composite{
                Layout: HBox{},
                Children: buttons,
            },
        },
    }.Create()
}
```

### Integration dengan Boot Process

```go
func (a *App) initializeBackend() {
    for _, stage := range stages {
        a.splash.SetStatus(stage.name + "...")

        if err := stage.handler(); err != nil {
            a.startupError = &AppError{
                Level:     LevelError,
                Stage:     stage.name,
                Message:   fmt.Sprintf("Failed to %s", strings.ToLower(stage.name)),
                Err:       err,
                Retriable: true,
            }
            return
        }
    }
}

func (a *App) showMainApp() {
    a.initOnce.Do(func() {
        if a.startupError != nil {
            go showErrorDialog(a.startupError)
            return
        }

        runtime.WindowShow(a.ctx)
        // ...
    })
}
```
